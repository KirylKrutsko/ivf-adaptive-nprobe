Limitations and next steps

Limitations

  • Two dense datasets, one index type
  • Time gain small: ≤ 1.12×, none at recall 0.8
  • Rules tied on SIFT1M only; on Deep1M the stopping rule saves more work
  • A cap of 256 cells for every method

Next

  • Cheaper centroid search for far centroids
  • Other, more diverse datasets
  • Parallel and GPU evaluation
  • Billion-scale indexes (Deep1B, SIFT1B)

Recap

Measure oracle
  • Queries need 1 to 200+ cells
  • Per-query choice: up to 2× at 0.9
Diagnose ratio rule
  • Constant ε: more work, not less
  • Ranks queries right, floods the hard ones
Learn two rules
  • 1.16–1.38× less work, 3 features each
  • Fitted rule: up to 1.12× faster in C++
